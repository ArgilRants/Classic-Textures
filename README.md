# Classic Textures
![Mod Icon made by zebragoboom](/readme_assets//icon.webp "Mod Icon made by zebragoboom")

Classic Textures is a Balatro mod that, with help from [Malverk](https://github.com/Eremel/Malverk), adds set of texture packs with the aim to bring back reworked or otherwise unseen textures from days past.
