## Version 1.1.0
### Additions
- 4 credits Jokers for each of the people who created/helped create the mod (Shown in credits tab)
- Added old [Erratic Deck](https://balatrowiki.org/w/Erratic_Deck#Trivia) sprite to Changed Sprites Pack
- Added old [The Soul](https://balatrowiki.org/w/The_Soul#Trivia) sprite to Changed Sprites Pack
- Added old [Gold Seal](https://balatrowiki.org/w/Gold_Seal#Trivia) sprite to Changed Sprites Pack
- Added old [Shoot the Moon](https://balatrowiki.org/w/Shoot_the_Moon#Trivia) sprite to Unused Sprites Pack redrawn by zebragoboom
- Added new option for "Bordered" 'sinful' Jokers
- Localization for Star Stake Stickers Pack
- Added a good ol. layer of polish

### Changes
- Renamed Unused Joker Sprites Pack -> Unused Sprites Pack
- Renamed Changed Joker Sprites Pack -> Changed Sprites Pack
- Rewrote Credits and Config tabs
- Some random qol stuff
- Many localization changes
- Badges now only display when the alt texture is enabled in the config for that pack

### Fixes
- Fixed issue where 'Classic Textures' badge was not displaying on cards with the polychrome edition
- Fixed dependancies

## Version 1.1.1
### Fixes
- Fixed Invisible and Soul not re-enabling their shaders when disabled by the config of the changed sprites pack (now you can disable them and they look like vanilla again!)
